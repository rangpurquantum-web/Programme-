# ProgramFlow

1. Create a free MongoDB Atlas cluster, allow access from anywhere (0.0.0.0/0), copy the connection string.
2. Push this folder to GitHub, import the repo in Vercel.
3. In Vercel > Settings > Environment Variables add MONGODB_URI, then redeploy.
4. Open the site, create a program, add items, press "Go live", open the live screen on any device.
